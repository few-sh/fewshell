Fewshot releases Fewshell

The mobile AI-assistant for DevOps practitioners and on-calls.

Already have Fewshell? Set it up

Fewshot Corp announced the private beta of Fewshell, a mobile AI-assistant for devops practitioners and on-calls that focuses on quality-of-life allowing full management of cloud and on-premise infrastructure on the go without sacrificing effectiveness, speed and security.

Infrastructure management and on-call has been a long-standing pain point for engineering teams across industries. Being on-call is a particularly dreaded part of the job for many software engineers and devops, requiring the on-call engineer to be within minutes of their laptop at all times.

FAQ

How does it work?
The app combines an AI-assisted chat interface, a copilot for infrastructure control, allowing you to manage infrastructure using instructions to the AI and approving every command as you would normally do in an AI-assisted environment.
Is it reliable?
We believe that the most reliable systems are the ones that have the least amount of moving parts. In its default deployment, Fewshell runs locally on your phone. The only other requirement is that it has access to an LLM provider and to your cloud. That’s it. There are no cloud-based management or control planes involved, no wrappers or services.
Is it safe?
Yes, you get to approve and/or edit every command before it’s run. Even if you do not believe in AI agents or don’t trust AI, you can simply use it to speed up your typing of shell commands.
Is it secure?
It is as secure as you allow your phone to be. The execution environment runs locally on your phone and any keys/secrets such as AWS account keys are stored in your device’s secure keychain. There is no third-party cloud that asks for your keys. The keys are always redacted from the AI agent. In some ways it can be more secure than a laptop, because iOS is a more restricted execution environment. As long as you do not approve any command that sends the key to some unauthorized actor, it can be as secure as you need.
Is it fast?
It is as fast as your local network allows you to be. While an iOS device might not necessarily match with the power of a desktop or a laptop, for most infrastructure and shell commands, it is more than enough. Alternatively, we offer a control plane appliance agent that allows you to run the environment on premise or in your cloud, Fewshell would act as the thin client and allow you to control the environment through the appliance.
Which cloud providers does it work with?
Any cloud provider that has a CLI tool or an API. If it can be controlled from a linux shell environment, it should work.
Does it work on premises?
As long as your network allows it. For example, if you are using VPN to connect to your on-premise infrastructure, it should work.
Does it work on Android?
We are targeting an Android release at a later date.
