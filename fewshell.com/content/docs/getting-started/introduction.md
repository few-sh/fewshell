## What is Fewshell?

Fewshell is a mobile terminal agent designed for on-call infrastructure management and troubleshooting. It provides AI-assisted shell sessions that help you send commands to the cloud directly from your phone.

## Key Features

- **AI-Assisted Shell** — Get intelligent suggestions and automated command execution.
- **Multiple Projects** — Organize your infrastructure into separate projects.
- **Session Management** — Maintain multiple shell sessions with full chat history.
- **Secrets Management** — Securely store and manage credentials per project.
- **Snippets** — Save and reuse common commands and workflows.

## Architecture

Fewshell consists of a mobile/desktop front-end application and a server-side backend agent. The two communicate in real-time, enabling you to interact with remote servers seamlessly.
