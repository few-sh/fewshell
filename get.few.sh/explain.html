FewShell Host Setup Technical Deep Dive

Transparency report and code explanation for the get.few.sh setup script.

Overview

The get.few.sh script is a Bash utility designed to bootstrap a connection between your server and the FewShell mobile application. It automates the process of gathering necessary credentials (SSH keys, API keys) and transferring them securely to your phone via a QR code.

🔒 Privacy First: This script runs entirely on your local machine/server. No data is sent to any third-party server during the execution of this script. The QR code generated is rendered locally in your terminal.

Step-by-Step Breakdown

1. Environment Setup & Input Parsing

The script starts by defining color codes for readability and parsing command-line arguments. It checks for flags like --all-keys which increases the search depth for API keys. 

# Parse args
LIMIT_KEYS=5
SEARCH_LIMIT=20
for arg in "$@"; do
    if [[ "$arg" == "-a" || "$arg" == "--all-keys" ]]; then
        LIMIT_KEYS=1000
        SEARCH_LIMIT=1000
    fi
done
2. Project Naming

To help you organize connections in the app, the script attempts to guess a logical name for the current environment. It checks:

  1. Git configuration (if inside a repo)
  2. System hostname
  3. Falls back to "skip"

You are always prompted to confirm or override this name.

3. Public IP Detection

To allow the mobile app to connect, the script needs the server's external IP address. It queries trusted public APIs with a short timeout to prevent hanging. 

EXTERNAL_IP=$(curl -s --max-time 5 https://ifconfig.me || curl -s --max-time 5 https://api.ipify.org || echo "Unavailable")
4. API Key Discovery

This is the most complex part of the script. To save you from copy-pasting long keys from a browser, the script can scan your home directory for existing LLM provider keys.

  • Manual Entry: You can always paste a key directly.
  • Auto-Discovery: It uses rg (ripgrep) or grep to look for patterns like OPENAI_API_KEY=....

Safety Mechanisms:

  • Excludes huge directories like node_modules, .git, venv.
  • Excludes log files.
  • Checks for dummy values (e.g., "your_key_here").
  • Only scans the $HOME directory.

# Simplified grep command used internally
grep -rIE -m 5 \
    --include="*config*" --include="*env*" ... \
    --exclude-dir={.git,node_modules,...} \
    "$PATTERN" "$HOME"
5. SSH Key Configuration

The script ensures a dedicated SSH key pair exists for this connection. It does not reuse your main identity keys (like id_rsa) unless you manually specified that path (though the script defaults to a specific file).

  1. Checks for ~/.ssh/few.sh.
  2. If missing, generates a new Ed25519 key pair.
  3. Appends the public key to ~/.ssh/authorized_keys to authorize access.
  4. Reads the private key into memory to include in the QR code.
ssh-keygen -t ed25519 -f "$KEY_FILE" -N "" -q
cat "${KEY_FILE}.pub" >> "$HOME/.ssh/authorized_keys"
chmod 600 "$HOME/.ssh/authorized_keys"
6. QR Code Generation

Finally, the script bundles the gathered information into a JSON object and generates a QR code in the terminal.

The payload structure:

  • n: Project Name
  • i: Host (user@ip)
  • l: Provider Label (e.g., "openai")
  • k: API Key
  • s: SSH Private Key (stripped of headers to save space)
jq -n '{n: env.PROJECT_NAME, i: env.QR_HOST, ...}' | qrencode -m 2 -t UTF8

Note: This requires jq and qrencode installed on the system. If missing, the script will skip this step and ask you to install them.

FAQ

Is my API key sent to FewShell developers?

No. The script operates strictly on your machine. The API key is read from your file (or input), printed to the QR code on your screen, and then the script exits. The data transfer happens optically between your monitor and your phone camera.

Why does it need my SSH private key?

The FewShell app acts as an SSH client. To connect securely to your server without passwords, it needs the private key corresponding to the public key added to your authorized_keys file. The key generated is specific to this usage (~/.ssh/few.sh).

Can I review the code myself?

Absolutely. The script is delivered as a plain text bash file. You can inspect it before running:

curl -sSf https://get.few.sh/index.html > inspect_me.sh
less inspect_me.sh
