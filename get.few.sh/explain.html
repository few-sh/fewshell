2. Welcome Banner

This function simply prints the welcome message and outlines the steps the script will take. Transparency is key: it explicitly states that data is only used for the QR code and stored on your phone. 

get_project_name() {
    # Determine default project name
    local default_name="skip"

    # Try to get GitHub repo name first
    if [ -d .git ]; then
        local repo_url
        repo_url=$(git config --get remote.origin.url 2>/dev/null || echo "")
        if [ -n "$repo_url" ]; then
            # Extract repo name from various URL formats
            default_name=$(basename "$repo_url" .git 2>/dev/null || echo "skip")
        fi
    fi

    # Fallback to hostname if GitHub repo name not found
    if [ "$default_name" = "skip" ]; then
        local hostname_val
        hostname_val=$(hostname 2>/dev/null || echo "")
        if [ -n "$hostname_val" ]; then
            default_name="$hostname_val"
        fi
    fi

    # Interactive project name prompt
    echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${RESET}"
    echo -e "${BOLD}📝 Project Name${RESET}"
    echo -e ""
    read -p "$(echo -e "${YELLOW}Enter project name${RESET} [${GREEN}${default_name}${RESET}]: ")" input_name < /dev/tty

    # Use default if empty
    if [ -z "$input_name" ]; then
        PROJECT_NAME="$default_name"
    else
        PROJECT_NAME="$input_name"
    fi

    echo -e "${GREEN}✓${RESET} Project name: ${BOLD}${PROJECT_NAME}${RESET}"
    echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${RESET}"
    echo ""
}

You are always given a chance to override this guess with your own custom name.

5. API Key Discovery

This is the "magic" part. Instead of making you copy-paste long API keys from a browser, the script can scan your local files to find keys you've already configured.

Safety First:

  • It only looks for specific patterns (e.g., OPENAI_API_KEY=...).
  • It ignores sensitive folders like .ssh, .git, and huge folders like node_modules.
  • It ignores log files.
  • It runs locally; no file contents are sent anywhere.

configure_ssh() {
    echo -e "${BLUE}🔐 Configuring SSH keys...${RESET}"
    local key_file="$HOME/.ssh/few.sh"
    mkdir -p "$HOME/.ssh" && chmod 700 "$HOME/.ssh"

    if [ ! -f "$key_file" ]; then
        ssh-keygen -t ed25519 -f "$key_file" -N "" -q
        echo -e "${GREEN}✓${RESET} Created new SSH key pair"
    else
        echo -e "${GREEN}✓${RESET} Using existing SSH key pair"
    fi

    grep -qFf "${key_file}.pub" "$HOME/.ssh/authorized_keys" 2>/dev/null || cat "${key_file}.pub" >> "$HOME/.ssh/authorized_keys"
    chmod 600 "$HOME/.ssh/authorized_keys"
    PRIV_KEY=$(cat "$key_file")
    echo ""
}

6. SSH Configuration

To allow the mobile app to connect securely, we need an SSH key.

The script creates a dedicated key pair (~/.ssh/few.sh) just for this purpose. It does not touch or expose your personal identity keys (like id_rsa).

The public key is added to authorized_keys to grant access, and the private key is read into memory to be shared via the QR code. 

generate_qr_code() {
    if command -v qrencode >/dev/null 2>&1 && command -v jq >/dev/null 2>&1; then
        echo ""
        echo -e "${BLUE}📱 Generating QR Code...${RESET}"
        echo ""

        local qr_label=""
        # ... (label logic) ...
        
        local qr_ssh
        qr_ssh=$(echo "$PRIV_KEY" | grep -v "^-----" | tr -d '\n')
        local qr_host="$USER@$EXTERNAL_IP"

        # Export variables for jq
        export QR_HOST="$qr_host"
        export QR_LABEL="$qr_label"
        export SEL_VAL
        export QR_SSH="$qr_ssh"
        export PROJECT_NAME

        echo -e "${CYAN}╔════════════════════════════════════════════════════════════╗"
        echo -e "║                         ${BOLD}SCAN QR CODE${RESET}${CYAN}                       ║"
        echo -e "╚════════════════════════════════════════════════════════════╝${RESET}"
        echo ""
        jq -n '{n: env.PROJECT_NAME, i: env.QR_HOST, l: env.QR_LABEL, k: env.SEL_VAL, s: env.QR_SSH}' | qrencode -m 2 -t UTF8
        echo ""
        echo -e "${GREEN}✓${RESET} QR Code generated successfully!"
    else
        echo ""
        echo -e "${YELLOW}⚠${RESET}  Skipping QR code generation (missing dependencies)"
        echo -e "${DIM}   Install with: ${BOLD}sudo apt-get install -y qrencode jq${RESET}"
    fi
}

7. QR Code Generation

This is the final step. All the gathered info (Project Name, IP, API Key, SSH Key) is bundled into a JSON object.

qrencode turns this JSON into a QR code displayed right in your terminal. When you scan this with the FewShell app, it securely saves these credentials to your phone's keychain.
